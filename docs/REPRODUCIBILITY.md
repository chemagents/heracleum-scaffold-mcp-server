# Методы и границы воспроизведения

Статья: [10.3390/ijms27177947](https://doi.org/10.3390/ijms27177947). Закреплённая научная реализация: [commit a2d980330bd90275722d401c6c9ca246a536dd01](https://github.com/chemagents/chem-repro-suite/tree/a2d980330bd90275722d401c6c9ca246a536dd01).

## Исходные данные

DS1: 2008 записей; DS2: 102; объединение по идентификаторам: 2073. Анализ докинга использует 2055 ненулевых профилей по 44 мишеням. Токсикологические значения — сохранённые выходы ADMETlab.

Источники, лицензии и контрольные суммы доступны в [манифесте](https://github.com/chemagents/chem-repro-suite/blob/a2d980330bd90275722d401c6c9ca246a536dd01/chem_repro/data/heracleum/manifest.json) и [NOTICE](https://github.com/chemagents/chem-repro-suite/blob/a2d980330bd90275722d401c6c9ca246a536dd01/NOTICE.md). Версия адаптера закрепляет конкретный код; изменение зависимости требует новой проверки. Исходные данные не исправляются автоматически ради совпадения с публикацией.

Для полной проверки переноса один вызов с endpoint="both", model="both", identity_policy="published_snapshot" выполняет четыре комбинации модель×эндпойнт при двух разбиениях, возвращает OOF и аудит фолдов. Bootstrap относится к фиксированным OOF-прогнозам, не к повторному обучению моделей.

## Что нужно учитывать при научной проверке

- `strict` используется по умолчанию. Для численной сверки архивной выборки требуется `identity_policy="published_snapshot"`; это явный выбор режима, а не исправление данных.
- Пороговые Tier обозначают относительный приоритет экспериментальной проверки, а не доказанные классы безопасности.
- Коэффициент Жаккара Tier1 зависит от основы идентичности: для снимка1,000 по исходным DS2-структурам и0,750 по master-структурам; strict0,857.
- Согласие каркасов, докинга и ADMETlab отражает согласованность вычислений по структуре; экспериментальная токсичность этим не подтверждается.

## Как проверить результат

1. Зафиксировать commit адаптера, backend, параметры и хеши исходных данных из ответа.
2. Выполнить запрос из [плана сценариев](../cases/README.md), сохранив реальные вызовы инструментов.
3. Скачать полные CSV/JSON, проверить SHA256, объём выборки, единицы и исключения. Превью таблицы не заменяет полный файл.
4. Сопоставить пересчёт с нужной таблицей или рисунком статьи. Отдельно обозначить опубликованные ссылки, повторное вычисление и реконструкцию.
5. Проверить текст CoScientist: совпадение числа недостаточно, если перепутаны эндпойнт, знаменатель, направление эффекта или происхождение оценки.

[Спецификация 9 сценариев](../cases/cases.json) содержит ожидаемые инструменты и научные проверки. Она является планом проверки, а не журналом успешных прогонов. Эталонные значения не следует передавать модели вместе с тестовым вопросом.

Установочная проверка в CI доказывает запуск, обнаружение инструментов и доставку файлов. Она не доказывает полного воспроизведения статьи или успешности всех итоговых отчётов CoScientist. [Текущий объём проверок](../validation/README.md).
